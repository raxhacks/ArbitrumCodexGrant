# Code of Conduct

## Our pledge

Arbitrum Codex is a developer resource. We want contributing to it — filing an issue, submitting a snippet, reviewing a pull request — to be a straightforward technical experience for everyone, regardless of experience level, background, or identity.

## Expected behaviour

- Keep discussion technical and specific. Review code, not people.
- Assume competence and good faith; ask for clarification before assuming a mistake.
- Accept that review of public example code is exacting. Precise criticism of a snippet is not a personal attack.
- Respect a maintainer's decision on scope. Not every proposal fits the library.

## Unacceptable behaviour

- Personal attacks, insults, or demeaning comments.
- Harassment of any kind, public or private.
- Publishing another person's private information without permission.
- Deliberately submitting malicious code, key-exfiltrating snippets, or misleading examples.
- Sustained disruption of issues, pull requests, or discussions.

## Scope

This applies in all project spaces — the repository, issues, pull requests, and any public space where someone is representing the project.

## Enforcement

Report unacceptable behaviour by opening a confidential report through the repository's private vulnerability reporting channel, or by contacting a maintainer directly. Reports are reviewed and acted on; the reporter's identity is not disclosed.

Maintainers may edit or remove comments, commits, code, and issues that violate this Code of Conduct, and may temporarily or permanently ban any contributor for behaviour they judge inappropriate, threatening, or harmful.
